# RnxSalidWorks

RnxSalidWorks — редактор параметрических деталей для Windows. При первом запуске открывается опорный кронштейн с эскизами, вытягиваниями и отверстиями.

## Запуск

Запустите `release/RnxSalidWorks-win32-x64/RnxCAD.exe`. Для переноса приложения скопируйте папку `RnxSalidWorks-win32-x64` целиком.

Для запуска из исходников понадобится Node.js 24.

```powershell
npm.cmd ci
npm.cmd start
```

Для работы в браузере запустите `npm.cmd run dev` и откройте адрес, который выведет Vite. Для повторной сборки Windows-приложения используйте `npm.cmd run package:win`.

## Работа с деталью

1. Выберите **Файл → Новая деталь** или отредактируйте кронштейн из примера.
2. Создайте эскиз на плоскости XY, XZ или YZ. Выберите прямоугольник, окружность или многоугольник, нарисуйте контур и при необходимости уточните размеры в панели свойств.
3. Завершите эскиз и примените вытягивание или вырез. Для отверстий используйте эскиз с окружностями. Смещение эскиза и направление операции определяют, с какой стороны детали начинается построение.
4. В дереве можно изменить параметры операций и их исходных эскизов. Изменения перестраивают деталь, её габариты, объём и массу.
5. Сохраните редактируемый проект как `.rnx` или экспортируйте треугольную модель в бинарный STL. Последний завершённый проект восстанавливается при запуске.

Вращение модели — левой кнопкой мыши, панорамирование — правой, масштабирование — колесом. `F` вписывает деталь в окно, `S` открывает эскиз, `E` запускает вытягивание. Размеры в проекте и при экспорте STL задаются в миллиметрах.

Эта версия рассчитана на отдельные детали. Размеры и координаты задаются явно, редактируемые проекты хранятся в формате `.rnx`, а готовая геометрия экспортируется в STL.

Для расчёта сеточной геометрии используется [Manifold](https://manifoldcad.org/docs/jsapi/documents/Using_Manifold.html), для просмотра модели — [Three.js](https://threejs.org/docs/), для приложения Windows — [Electron](https://www.electronjs.org/docs/latest/).
